# Тёплая крошка — тестовый сайт пекарни

Простой одностраничный сайт на HTML, CSS и JavaScript. Нажатие на карточку выпечки обновляет описание товара на этой же странице.

## Как открыть локально

Откройте файл `index.html` в браузере. Сервер и дополнительные библиотеки не нужны.

## Как получать обновления

Склонируйте репозиторий один раз:

```bash
git clone https://github.com/DemiZerO762/FirstSiteTest.git
cd FirstSiteTest
```

Чтобы получить последнюю версию позже, в папке проекта выполните:

```bash
git pull
```

Цены и описания — демонстрационные, их можно заменить в `index.html`.
